# Plan 03-01: IME host driver abstraction with MockDriver

## Objective

Introduce a producer-side `ImeHostDriver` trait so the runtime can accept
IME events from any host (winit, AppKit, browser, mock). Ship a `MockDriver`
that replays a `Vec<ImeOp>` script for tests. The receive side (Phase 2's
`handle_ime_preedit` and `is_focused_ime_enabled`) is unchanged; this plan
only adds the *source* of `UiEvent::ImePreedit` / `UiEvent::ImeCommit` for
desktop apps and tests.

## Context

Phase 2 wired the receive side: `ImePreedit` / `ImeCommit` events route to a
focused `Input` whose `ime_enabled` flag is true. The "real drivers" success
criterion in `03-CONTEXT.md` Decision 1 requires an abstraction so tests
verify the runtime's response without simulating an OS IME. The decision
locked in:

- Producer-side trait (runtime calls `driver.poll(&mut sink)` per frame)
- Sink pushes `UiEvent::ImePreedit` / `UiEvent::ImeCommit` into runtime event queue
- `MockDriver` replays a `Vec<ImeOp>` script
- `NoopDriver` is the default (backward-compatible)
- Preedit held in `InputState.preedit: Option<ImePreedit>` (already there)

## Notes

- This plan DOES NOT add winit / AppKit / browser adapters. Those are v1.x.
- The trait is sync; per `PROJECT.md` the hot path is sync. Async drivers wrap their own runtime.
- The `MockDriver`'s `fired: bool` field is optional; if omitted, the struct is `{ script, cursor }`.
- If `runtime::ime_host` ends up depending on `core::event` (it must, for `ImePreedit`), that is fine — `runtime` already depends on `core`.

## Threat model

- **Threat**: A malicious `ImeHostDriver` impl could push unbounded strings into the event queue, causing memory exhaustion.
- **Mitigation**: The `ImePreedit` and `ImeCommit` text are subject to the same downstream `InputState` limits as host-delivered events; no special handling.
- **Threat**: A driver that panics in `poll` could crash the runtime.
- **Mitigation**: `poll` is `&mut self` and not `unsafe`; a panicking driver crashes the calling thread, which is the same as any panicking host callback. Document the contract.
- **Severity**: low. No code execution, no network, no auth surface in this plan.
